# PED examples

These notebooks show how to use `soursop.ped` to find ensembles in the [Protein Ensemble Database (PED)](https://proteinensemble.org), load them into SOURSOP, and analyze them. They need an internet connection.

You can run each notebook locally or in Google Colab with nothing installed by clicking its badge. The Colab versions live in [`colab/`](colab/). They are the same notebooks, with an extra cell that installs SOURSOP and no saved output.

Downloaded ensembles are kept in `ped_cache/` and reused, so each ensemble is downloaded only once across all notebooks. That folder is git-ignored; you can delete it at any time to free space. Running all seven notebooks from scratch fills it with about 800 MB (44 ensembles) and takes about 10 minutes, mostly in notebook 4.
